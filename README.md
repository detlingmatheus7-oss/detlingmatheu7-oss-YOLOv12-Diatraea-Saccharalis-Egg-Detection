# detlingmatheu7-oss-YOLOv12-Diatraea-Saccharalis-Egg-Detection
Repositório do código fonte e dataset usados para gerar os modelos YOLOv12 no meu trabalho de iniciação cientifica
Para reproduzir o experimento é necessario fazer o upload da pasta project (descompactada)
O primeiro bloco deve ser executado e permitido o uso do drive pelo colab
Os proximos cinco devem ser executados em sequencia
obs: o quarto bloco serve para limpar os modelos antigos e cache, caso não tenha modelos apenas comentar a quarta linha
O sétimo bloco serve para gerar as augumentations
Os três últimos servem para testar o modelo gerado no quinto
